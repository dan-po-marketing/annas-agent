# Reflect Memory Hygiene

Use when the user asks to clean memory, when contradictions appear, or during monthly maintenance.

## Workflow
1. Separate durable facts, states, hypotheses, and contradictions.
2. Mark old claims as superseded instead of overwriting them.
3. Ask before deleting private memory.
4. Keep profile memory compact.
5. Do not promote daily scores into identity claims.

## User commands
- forget this
- mark outdated
- lower confidence
- what evidence do you have?
- is this pattern or current state?
