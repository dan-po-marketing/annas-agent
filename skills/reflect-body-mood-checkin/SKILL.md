# Reflect Body/Mood Check-in

Use for optional daily check-ins.

Ask only:
- mood 1–10;
- energy 1–10;
- body load / pain / illness / inflammation 1–10;
- sleep/recovery 1–10;
- overload/stress 1–10;
- old theme or new theme;
- main factor.

Do not analyze unless the user asks. Do not store the numbers as durable personality facts.
