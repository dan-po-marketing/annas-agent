# Reflect Onboarding

Use when the user starts the Reflect assistant or asks how to use it.

## Workflow
1. Explain Reflect in one short paragraph: thinking through states, patterns, conflicts, and change over time.
2. Explain memory hygiene: observations, states, hypotheses, contradictions, and stable preferences stay separate.
3. Ask the three calibration questions from `docs/onboarding-telegram.md`.
4. Offer optional check-ins and voice replies.
5. Save only stable preferences or explicit user instructions.

## Pitfalls
- Do not open with generic disclaimers.
- Do not ask a long questionnaire.
- Do not store early self-descriptions as permanent truth.
