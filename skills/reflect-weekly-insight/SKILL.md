# Reflect Weekly Insight

Use when the user asks for a weekly insight or a scheduled weekly synthesis runs.

## Workflow
1. Use recent material first.
2. Look for one hidden bridge across several observations.
3. Produce one tentative hypothesis.
4. Include a short evidence bridge.
5. End with a calibration question.

## Pitfalls
- Do not produce a generic summary.
- Do not reuse old successful insights as new ones.
- Do not let old self-analysis dominate recent evidence.
